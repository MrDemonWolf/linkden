# 🐳 Docker Self-Hosting

Run LinkDen on any Linux server, VPS, or local machine using Docker.

### ⚡ Summary
- **Type:** Self-hosted (VPS/Local).
- **Database:** SQLite (Volume persisted).
- **Server:** Node.js (Hono adapter).
- **Frontend:** Next.js (Static export + Caddy).

---

## 1. ✅ Prerequisites

- [ ] **Docker 20.10+**
- [ ] **Docker Compose v2+**
- [ ] A domain name (for SSL/Production).

---

## 2. 🚀 Quick Start

Get up and running in 3 commands.

```bash
# 1. Clone
git clone https://github.com/mrdemonwolf/linkden.git
cd LinkDen

# 2. Configure
cp .env.example .env
# (Edit .env with your secrets!)

# 3. Launch
docker compose up -d
```

> **Done!** Visit `http://localhost:3001/admin/setup` to create your admin account.

---

## 3. ⚙️ Environment Variables

Create your `.env` file.

### Required
```bash
BETTER_AUTH_SECRET=your-random-secret-here
BETTER_AUTH_URL=https://api.yourdomain.com
NEXT_PUBLIC_SERVER_URL=https://api.yourdomain.com
NEXT_PUBLIC_SITE_URL=https://yourdomain.com
CORS_ORIGIN=https://yourdomain.com
```

### Optional (But Recommended)
```bash
NEXT_PUBLIC_SITE_NAME=LinkDen
RESEND_API_KEY=sk_...
RESEND_FROM_EMAIL=me@mydomain.com
```

> **Tip:** Generate a secret with `openssl rand -base64 32`.

## 4. 🗄️ Architecture

### ⚠️ Critical Data Warning
Your database lives in a **Docker Volume** (`linkden-data`).
- **DO NOT** delete this volume unless you want to wipe your data.
- **DO NOT** run `docker compose down -v` unless you are sure.

### The Stack
1. **Frontend:** `linkden-web` (Port 3001) - Serves static files via Caddy.
2. **Backend:** `linkden-api` (Port 8787) - Node.js API.
3. **Database:** SQLite file mapped to `/data/linkden.db`.

---

## 5. 🔄 Backups

Back up your data regularly.

### Manual Backup
```bash
docker exec linkden-api sqlite3 /data/linkden.db ".backup /data/backup.db"
docker cp linkden-api:/data/backup.db ./linkden-backup.db
```

### Restore
```bash
docker compose stop api
docker cp ./linkden-backup.db linkden-api:/data/linkden.db
docker compose start api
```

## 6. 🌐 Reverse Proxy (SSL)

For production, put Caddy or Nginx in front.

### Option A: Caddy (Easiest)
Add this to your `docker-compose.yml`:

```yaml
services:
  caddy:
    image: caddy:2-alpine
    ports: ["80:80", "443:443"]
    volumes:
      - ./Caddyfile:/etc/caddy/Caddyfile
      - caddy-data:/data
```

**Caddyfile:**
```
yourdomain.com {
    reverse_proxy web:3001
}
api.yourdomain.com {
    reverse_proxy api:8787
}
```

## 7. 🛠️ Troubleshooting

### Container keeps restarting?
Check logs:
```bash
docker compose logs api --tail=100
```
*Usually missing env vars.*

### CORS Errors?
Make sure `CORS_ORIGIN` matches your **Frontend URL** exactly.
- ✅ `https://yourdomain.com`
- ❌ `https://yourdomain.com/` (No trailing slash!)

### Database empty after restart?
Did you run `docker compose down -v`? That deletes volumes.
**Always use** `docker compose down` (without `-v`) to stop.
