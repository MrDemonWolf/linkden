# ☁️ Cloudflare Deployment

Deploy LinkDen to Cloudflare's free tier with two Workers and a D1 database. LinkDen was built for this.

### ⚡ TL;DR
- **Hosting:** Cloudflare Workers (Free tier is plenty).
- **Database:** Cloudflare D1 (SQLite).
- **Tooling:** Alchemy (IaC) handles the heavy lifting.
- **Command:** `bun ship` deploys everything.

---

## 1. ✅ Prerequisites

- [ ] A **Cloudflare account** (free tier works).
- [ ] **Node.js 20+** and **[Bun](https://bun.sh)** installed.
- [ ] Your LinkDen repo cloned:

```bash
git clone https://github.com/mrdemonwolf/linkden.git
cd LinkDen
bun install
```

---

## 2. 🔑 Step 1: Cloudflare API Token

Create a token so LinkDen can manage your resources.

1. Go to **Profile > My Profile > API Tokens** in the Cloudflare dashboard.
2. Click **Create Token** > **Custom token**.
3. Add these **Edit** permissions:
   - `Account` -> `Cloudflare Workers Scripts`
   - `Account` -> `D1`
   - `Account` -> `Workers KV Storage`
4. Select your **Account** under Account Resources.
5. **Copy the token!** (It's only shown once).

---

## 3. 🆔 Step 2: Account ID

1. Find your **Account ID** on the Cloudflare dashboard overview page (right sidebar).
2. Or run: `npx wrangler whoami`.

---

## 4. ⚙️ Step 3: Configure `.env`

Create a `.env` file in the project root:

```bash
# Cloudflare Credentials
CLOUDFLARE_API_TOKEN=your-api-token
CLOUDFLARE_ACCOUNT_ID=your-account-id

# App URLs (Use placeholders first, update after deploy)
NEXT_PUBLIC_SERVER_URL=https://linkden-server.<your-subdomain>.workers.dev
CORS_ORIGIN=https://linkden-web.<your-subdomain>.workers.dev

# Better Auth
BETTER_AUTH_SECRET=your-random-secret
BETTER_AUTH_URL=https://linkden-server.<your-subdomain>.workers.dev
```

> **Tip:** Generate a secret with `openssl rand -base64 32`.

---

## 5. 🚀 Step 4: Deploy

```bash
bun ship
```

**What happens?**
Alchemy automatically creates your D1 database, runs migrations, sets up R2 storage, and deploys your Workers.

### 🔄 Important: Update URLs
Once the command finishes, it will output your real Worker URLs. **Update your `.env`** with these URLs and run `bun ship` one more time to sync them.

---

## 6. 👤 Step 5: Setup Admin

1. Visit: `https://linkden-web.<subdomain>.workers.dev/admin/setup`.
2. Create your account.
3. **First user becomes admin.** Registration locks automatically after that.

---

## 7. 🌐 Step 6: Custom Domains (Optional)

1. Go to **Workers & Pages** in Cloudflare.
2. Select your Worker > **Settings > Domains & Routes** > **Add Custom Domain**.
3. Update your `.env` URLs and run `bun ship` again.

---

## 🛠️ Common Commands

- `bun ship` - Update/Redeploy.
- `wrangler tail linkden-server` - See live API logs.
- `bun destroy` - **Irreversible.** Delete all Cloudflare resources.

For a typical single user, LinkDen stays **100% within the Free Tier**.
