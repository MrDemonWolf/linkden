title: Quick Start
description: Create your profile, add content, and understand preview and publication.
---

Start with the [local installation](/docs/getting-started/installation) or an instance your operator has already configured.

## 1. Create your administrator account

Open `/admin/setup`. Enter your name, email, password, and the setup token if one is configured. Complete the **Profile**, **Theme**, and **Done** steps.

The first account becomes the single administrator. If setup is complete, sign in at `/admin/login`.

## 2. Add your first link

1. Open **Profile page → Blocks** at `/admin/links`.
2. Choose **Add block → Link**.
3. Enter a title and an HTTP or HTTPS destination.
4. Choose an icon or card style if needed, then save the block.
5. Use **Apply n new** above the block list to include new blocks in the saved page content. This is separate from publishing an assets-only public revision.

Saving and including blocks prepares the source for publication. On an assets-only deployment, the public page keeps its previous revision until a publication succeeds.

## 3. Make the page yours

- **Profile page → Profile:** name, avatar, bio, and badge.
- **Profile page → Social:** find networks, enter handles or URLs, toggle visibility, and save.
- **Design → Theme:** public theme, colors, desktop layout, and social icon shape.
- **Design → Banner:** a preset banner or your own image.
- **Design → Branding:** public branding, legal notices, vCard, and embedded-media consent.
- **Design → SEO:** title, description, and share image.

The desktop preview sits beside your editing tools and can be collapsed. On smaller screens, use **Preview** in the header. It has light/dark controls and a plain document canvas. Its buttons, forms, and embeds are inert placeholders; test them on the real page.

Choose **Side by side** or **Stacked** under Design → Theme. Mobile always places the profile above a single column of blocks.

## 4. Set up the features you need

| Task | Location |
| --- | --- |
| Accept messages | **Inbox → Accepting messages** |
| Configure Resend and delivery mode | **Settings → Email** |
| Configure CAPTCHA | **Settings → Integrations** |
| Enable TOTP and save backup codes | **Settings → Account** |
| Design and download a private Wallet pass | **Settings → Wallet** |
| Export a backup or import existing data | **Settings → Data** |

Profile pages and their buttons do not collect analytics.

## 5. Review publication

Open the publishing status in the header. Save or discard unsaved edits first. When an approved target and runner are enabled, **Publish** requests a public revision; **Published** requires a verified receipt.

If publication is unavailable, the status explains the missing setup. Saving locally does not enable cloud publication. Scheduled content also needs the publication scheduler; its status explains the configured cadence or need for a manual publish.

Use **View live** to inspect the current public page. Confirm the intended content and interactions before sharing its URL.

Continue with [Blocks](/docs/guide/blocks) or [Security](/docs/guide/security).
