# 🚀 Quick Start

You'll go from a fresh install to a live link page in about five minutes.

> **Pre-requisite:** If you haven't installed LinkDen yet, start with the [Installation Guide](/docs/getting-started/installation).

---

## 1. 👤 Create Your Admin Account

Navigate to `/admin/setup` in your browser.

- [ ] Enter your **Name**
- [ ] Enter your **Email**
- [ ] Create a **Password**
- [ ] Enter the **Setup token** if your deploy sets `SETUP_TOKEN`
- [ ] Click **Create Account**

> **Note:** The first user becomes the admin and registration locks automatically.

---

## 2. 🧱 Add Your First Blocks

Go to `/admin/links`.

- **Left:** Your blocks.
- **Right:** Live phone preview (the preview button on mobile).

### Try adding a link:
1. Click **Add Block** → Select **Link**.
2. Fill in **Title** (button text) and **URL**.
3. (Optional) Customize colors/icons in the **Style** section.
4. Click **Save Changes**.
5. Click **Publish 1 new** in the header. New blocks start unpublished; edits to published blocks go live immediately.

---

## 3. 🌐 Set Up Social Icons

Go to `/admin/links/social`.

- [ ] Search for your platform (e.g., "GitHub", "Twitter").
- [ ] Toggle it **ON**.
- [ ] Enter your handle or paste your profile URL, then save.

> **Tip:** Dark mode is automatic for brand icons!

---

## 4. ⚙️ Configure Settings

- **Profile:** `/admin/links/profile` -- display name, avatar, bio.
- **SEO:** `/admin/design/seo` -- page title, description.
- **Messages:** `/admin/inbox` -- toggle **Accepting messages**.
- **Branding:** `/admin/design/branding` -- remove LinkDen branding.
- **Account, email, integrations, wallet, data:** `/admin/settings`. Turn on **two-factor authentication** under Account.

---

## 5. 🎉 View Your Public Page

Click **View Page** in the header.
**That's it!** Share your URL anywhere.
