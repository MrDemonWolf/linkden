## Operating an instance

The operator is responsible for its content, data handling, credentials, integrations, deployment security and applicable legal obligations. This includes configuring its own privacy/visitor terms, protecting the admin and first-run setup, reviewing imported content, choosing providers, and maintaining backups and recovery procedures.

Native publication creates a separate public version. Removing data in the editor does not automatically withdraw already published files, earlier provider versions, emails or backups. Operators must manage those copies and any required takedown or retention process.

Using LinkDen does not approve changes to production, DNS, routes, certificates, billing or existing data. Those remain decisions for the authorized operator.
