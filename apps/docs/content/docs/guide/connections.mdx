# 🤝 Inbox

When visitors fill out your contact form, their messages land in the **Inbox** at `/admin/inbox`. Think of it as a simple read-only inbox built into your admin panel — no external tools required.

### ⚡ TL;DR
- Messages from your contact form appear here automatically.
- Filter by **All**, **Unread**, or **Read**.
- Select any message to read the full details.
- Older messages load page by page ("Showing n of total").
- **Select** mode marks read or deletes several messages at once.

---

## 📬 What You'll See

Each connection card shows:
- **Name** and **email** of the visitor.
- **Message preview** (first line).
- **Timestamp** of when it was submitted, in the timezone set under Settings → Account.
- **Read/Unread indicator** — bold title = unread.

Clicking a card opens the full message in a side panel (desktop) or a slide-up sheet (mobile).

---

## 🔍 Filtering

Use the filter buttons at the top of the list:

| Filter | Shows |
|--------|-------|
| **All** | Every submission |
| **Unread** | Only messages you haven't opened yet |
| **Read** | Messages you've already viewed |

> Opening a message marks it as **read** once. If you then choose **Mark as unread**, it stays unread.

Scroll to the bottom and click **Load older messages** to see more.

---

## ✅ Actions

### Single Connection
- **Mark as read / unread** — Toggle the read state manually.
- **Delete** — Permanently removes the connection. Cannot be undone.

- **Reply** — Opens your mail app addressed to the visitor. The address is encoded, so a crafted email can't add extra recipients or headers.

### Bulk Actions
1. Click **Select** in the list header and tick one or more messages.
2. Use the toolbar that appears:
   - **Mark read** — Marks the selected messages as read.
   - **Delete** — Permanently deletes the selected messages (after a confirmation).

> **Warning:** Deletion is permanent. There is no recycle bin.

---

## ⚙️ Prerequisites

Messages only appear here while **Accepting messages** (in the Inbox header) is on and visitors have submitted the form.

1. Go to `/admin/inbox`.
2. Turn on **Accepting messages** in the header.
3. Optionally configure email at `/admin/settings/email` to get notified.

See the [Contact Form guide](/docs/guide/contact-form) for full setup.

---

## 📧 Email Notifications (Optional)

If you'd rather get an email for each new submission than check this inbox:

1. Go to `/admin/settings/email`.
2. Set your email provider: Resend (Cloudflare Email Workers coming soon), API key and sender address.
3. Under **Contact-form delivery**, choose **Email only** or **Inbox and email**. In Email only mode a failed send still lands here.

See [Email Templates](/docs/guide/email-templates) for what the notification looks like.
