Open **Profile page → Blocks** at `/admin/links`. Add, edit, hide, and reorder content. Social icons are managed separately under **Profile page → Social**.

## Block types

| Type | What it does |
| --- | --- |
| **Link** | Opens an HTTP or HTTPS destination; choose a button, thumbnail, or featured-image card, with an optional icon |
| **Header** | Adds an aligned section heading with H1–H6 size choices; the profile remains the page's top-level heading |
| **Embed** | Shows YouTube, Spotify, SoundCloud, or a custom HTTPS iframe destination that permits embedding |
| **Connect** | Opens a contact form with name, email, optional message, consent, and an optional where-we-met question |
| **vCard** | Downloads this block's contact details as a `.vcf` file |
| **Location** | Shows an address and optional Google Maps, Apple Maps, or custom outbound link |
| **Image** | Shows an uploaded image, alt text, caption, aspect ratio, and Contain or Cover fit |
| **Text** | Shows up to 2,000 characters of plain text |
| **Divider** | Separates content with a line, dots, or empty space |

Custom iframe providers can refuse embedding or require additional deployment CSP configuration. With embedded-media consent on, external media stays behind a click-to-load gate until allowed.

Connect blocks require **Inbox → Accepting messages**. The optional **Ask where we met** question is also enabled by the Connect preset. See [Contact form](/docs/guide/contact-form) for CAPTCHA and delivery setup.

## Add and edit

1. Choose **Add block**, then select a type.
2. Enter content and use the applicable Style controls.
3. Open **Schedule** for start/end times or **Advanced** for a validated JSON config object.
4. Save the block.

New blocks start as drafts. **Apply n new** above the list includes them in the saved page content. **No block drafts** means every block has been applied; it does not confirm a public deployment.

On the legacy dynamic page, enabled, applied blocks appear immediately. An assets-only public page keeps its last verified revision until the header's separate **Publish** action succeeds. Check that publishing status before sharing changes.

Your editor preview includes eligible drafts and unsaved edits. A saved page with all blocks disabled or hidden shows an empty page; sample links appear only when there are no saved blocks.

## Order, visibility, and deletion

Drag the grip handle to reorder, or use the keyboard drag controls; the resulting position is announced and saved. The eye control hides a block without deleting it.

Delete asks for confirmation. The toast's **Undo** restores the block at its previous position; deleted historical click records are not restored.

## Responsive page layout

Under **Design → Theme → Page layout**:

- **Side by side:** on wide pages, the profile stays sticky on the left and blocks form one full-width vertical list on the right.
- **Stacked:** the profile appears above that same block list.
- **Mobile:** always one column, with each block on its own row.

Legacy saved header grid/carousel values remain accepted for compatibility. The current renderer stacks section content; headers do not create a mobile carousel or multi-column block grid.

For images, **Contain** keeps the whole image visible and **Cover** fills the selected aspect ratio by cropping. Use alt text to describe meaningful image content.

## Preview and the public page

The desktop preview is a collapsible plain document viewport beside the editing tools. Smaller screens use the header **Preview** action. Light/dark controls affect the preview only.

Scroll to review layout, but the preview is inert: links, embeds, and contact actions do not execute. Use **View live** to test actual interactions.

The legacy dynamic renderer reads saved, enabled, published blocks directly. An assets-only public page instead keeps its last verified revision until the header's **Publish** action succeeds. Its scheduled changes use the configured publication scheduler and can be delayed; review the publishing status before relying on timed content.
