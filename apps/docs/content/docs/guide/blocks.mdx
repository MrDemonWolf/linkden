# 🧱 Blocks

Build your page by adding blocks in the builder at `/admin/builder`. LinkDen supports **7 block types** that you can mix, match, and reorder however you like.

### ⚡ Summary
- **7 types:** Link, Header, Social Icons, Embed, Form, vCard, Location.
- **Drag & Drop:** Reorder anything.
- **Preview:** Live phone frame on the right.
- **Schedule:** Show/hide blocks automatically by date.
- **Style:** Custom colors, borders, and animations per block.

---

## 🏗️ Block Types

### 🔗 Link
The most common block. A clickable button to any URL.
- **Includes:** Title, URL, Icon.
- **Styles:** Outline, fill, text alignment, emoji.

### 📝 Header
A text heading to organize your page.
- **Includes:** Title text.
- **Styles:** H1-H6, divider lines, alignment.

### 🌐 Social Icons
A row of icons linking to your profiles.
- **Source:** Uses networks from `/admin/social`.
- **Styles:** Size, spacing, brand colors (auto dark mode).

### 📺 Embed
Embed media directly on your page.
- **Supported:** YouTube, Spotify, SoundCloud, or **any custom URL**.
- **Styles:** Aspect ratio, max width.

### ✉️ Form
An inline contact form. Visitors message you directly.
- **Presets:** Contact, Feedback, RSVP.
- **Styles:** Button text, success messages.
> **Note:** Requires setup in `/admin/settings` first.

### 📇 vCard
A **"Download Contact"** button.
- **Action:** Generates a `.vcf` file for visitors.
- **Data:** Pulls from your profile settings.

### 📍 Location
An embedded map showing a physical address.
- **Includes:** Address text, optional label.
- **Provider:** Apple Maps (via MapKit JS) when configured, Google Maps embed otherwise.
- **Styles:** Height, zoom level.
> **Note:** MapKit JS token is optional. See `/admin/settings` → **Map** to enable Apple Maps.

## 🛠️ Managing Blocks

### Adding
1. Go to `/admin/builder`.
2. Click **Add Block**.
3. Select a type.

### Editing
Click any block to open the slide-in panel:
- **Content:** Main fields (URL, Title).
- **Style:** Colors, Icons, Borders.
- **Options:** Animation, `newTab`, `noFollow`.
- **Schedule:** Set start/end dates for visibility.

### Reordering
**Drag & Drop** any block by the grip handle on the left. Autosaves immediately.

### Hiding (Visibility)
Click the **Eye Icon** 👁️ to toggle visibility without deleting.
- Great for drafting content.
- Perfect for seasonal links.

### Deleting
Click the **Trash Icon** 🗑️ to permanently remove.

## 📱 Phone Preview
The right side shows a **live preview**.
- **Interactive:** Scroll and click to test.
- **Mobile Toggle:** Use the floating button on small screens.
- **Dark Mode:** Test your theme in both light and dark modes.
