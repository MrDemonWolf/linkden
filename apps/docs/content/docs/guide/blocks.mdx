# 🧱 Blocks

Build your page by adding blocks at `/admin/links`. LinkDen supports **9 block types** that you can mix, match, and reorder however you like. Social icons are not a block: add them at `/admin/links/social` and they appear under your profile.

### ⚡ Summary
- **9 types:** Link, Header, Embed, Connect (contact form), vCard, Location, Image, Text, Divider.
- **Drag & Drop:** Reorder anything.
- **Preview:** Live phone frame on the right.
- **Schedule:** Show/hide blocks automatically by date.
- **Style:** Custom colors, borders, and shadows per block.

---

## 🏗️ Block Types

### 🔗 Link
The most common block. A clickable button to any URL.
- **Includes:** Title, URL, Icon (Lucide icons and brand logos).
- **Card style:** Button, Thumbnail (small image), or Featured image (16:9).
- **Styles:** Colors, border radius, shadow, alignment.

### 📝 Header
A text heading to organize your page.
- **Includes:** Title text.
- **Styles:** H1-H6, alignment.
- **Layout for blocks below:** List, grid, or carousel.

### 📺 Embed
Embed media directly on your page.
- **Supported:** YouTube, Spotify, SoundCloud, or **any custom URL**.
- **Privacy:** while the consent banner is on, an embed shows a click-to-load placeholder until the visitor allows **Embedded media**, because the provider receives the visitor's IP once it loads.

### ✉️ Connect (contact form)
An inline contact form. Visitors message you directly; messages land in your Inbox.
- **Fields:** First and last name, email, an optional message, a required consent checkbox, and an optional **Ask where we met** question (off unless you switch it on or use the Connect preset).
- **Spam protection:** CAPTCHA when configured, plus a hidden honeypot field.
> **Note:** Turn on **Accepting messages** at `/admin/inbox` first.

### 📇 vCard
A **"Save contact"** button.
- **Action:** Downloads a `.vcf` file with this block's contact details.
- **Note:** the footer **Save vCard** button uses the first visible vCard block, or the vCard under Design → Branding when there is none.

### 📍 Location
An address card with an optional "open in maps" link.
- **Includes:** Address text, optional coordinates.
- **Link:** Google Maps, Apple Maps, a custom URL, or none.
> **Note:** No map is embedded on the page, so no map provider is contacted until the visitor clicks the link.

### 🖼️ Image
A single uploaded image with alt text, an optional caption, and an aspect ratio (auto, 16:9, 1:1, 4:5).

### 🔤 Text
A paragraph of plain text (up to 2,000 characters) with alignment.

### ➖ Divider
A visual separator between sections: a line, dots, or empty space.

## 🛠️ Managing Blocks

### Adding
1. Go to `/admin/links`.
2. Click **Add Block**.
3. Select a type.

New blocks start **unpublished**; **Publish n new** in the header puts them on your page. Editing, reordering or hiding a block that is already published takes effect immediately.

### Editing
Click any block to open the editor panel:
- **Content:** Main fields (URL, Title).
- **Style:** Colors, Icons, Borders.
- **Schedule:** Set start/end dates for visibility.
- **Advanced:** Raw config (must be a JSON object).

### Reordering
**Drag & Drop** any block by the grip handle on the left, or use the keyboard (the new position is announced). Saves immediately.

### Hiding (Visibility)
Click the **Eye Icon** 👁️ to toggle visibility without deleting.
- Great for drafting content.
- Perfect for seasonal links.

### Deleting
Click the **Trash Icon** 🗑️ and confirm. **Undo** in the toast puts the block back in its old spot, but its click history is gone for good.

## 📱 Phone Preview
The right side shows a **live preview**.
- **Interactive:** Scroll and click to test.
- **Mobile Toggle:** Use the floating button on small screens.
- **Dark Mode:** Test your theme in both light and dark modes.
