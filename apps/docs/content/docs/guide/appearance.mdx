# 🎨 Appearance & Themes

Everything visual lives at `/admin/design` (Theme · Banner · Branding · SEO). Changes preview instantly in the phone on the right (tap the preview button on mobile).

### ⚡ Quick Look
- **Presets:** 11 themes, each with light and dark variants.
- **Custom:** Override any color, in both light and dark.
- **Banners:** Gradients or custom images.
- **Social icon shape:** Circle or rounded square.
- **Consent banner:** On by default; asks visitors before analytics and embeds.
- **CSS:** Full custom code support.

## 🎨 Custom Colors

Override individual colors on top of any preset.
- **Primary:** Buttons & Links.
- **Secondary:** Supporting elements.
- **Accent:** Highlights.
- **Background:** Page background.

> **Note:** Overrides apply in **both light and dark mode**. Leave a field empty to use the preset's own color in each mode. Colors saved with an older version stay pinned until you clear them.

---

## 🌓 Color Mode

Control what visitors see first.

- **Light:** Always light.
- **Dark:** Always dark.
- **System:** Matches their device (iOS/Android/Windows). Chromium browsers get the right mode on first paint; others switch instantly after load.

## 🍪 Consent Banner

The consent banner is **on by default**, and it is what decides whether a visitor is counted in your analytics.

- **Banner on (default):** a new visitor's page views and link clicks are recorded only after they accept **Analytics**. Embedded media (YouTube, Spotify, SoundCloud, custom embeds) shows a click-to-load placeholder until they click **Load** or allow **Embedded media**. A first visit is counted the moment they accept.
- **Banner off:** analytics are recorded for **every visitor without asking**, and embeds load immediately. If you turn it off, you need another lawful basis for analytics (ask your own counsel), and your privacy notice should say so.

Visitors can change their mind any time with the **Cookie settings** link in the footer. A choice expires after 12 months, or sooner when LinkDen changes what it asks. Escape hides the banner for the current page view without recording a choice.

To configure it:

1. Go to `/admin/design/branding` → **Consent Banner**.
2. Leave **Show consent banner** on (or turn it off, with the caveat above).
3. Edit the banner text and the privacy-policy link (it falls back to your branding privacy URL).

## 💻 Custom CSS

For advanced users. Add your own styles.

### Useful Classes
- `.ld-page` - Main container.
- `.ld-profile` - Profile section.
- `.ld-link-block` - Link buttons.
- `.ld-social-block` - Social icons under your profile.
- `.ld-contact-block` - Contact (Connect) form.
- `.ld-header-block`, `.ld-embed-block`, `.ld-image-block`, `.ld-text-block`, `.ld-divider-block`, `.ld-location-block`, `.ld-vcard-block` - The other block types.

> The admin preview scopes your CSS to the phone frame and strips external `url()` / `@import` fetches; the live page applies it as written.

### CSS Variables
`--ld-primary`, `--ld-accent`, `--ld-background`, `--ld-foreground`, `--ld-card`, `--ld-card-foreground`, `--ld-border`, `--ld-muted`, `--ld-muted-foreground`

```css
/* Example: Gradient Background */
.ld-page {
  background: linear-gradient(135deg, var(--ld-primary), var(--ld-accent));
}
```
