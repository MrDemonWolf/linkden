Public design lives at `/admin/design` (Theme · Banner · Branding · SEO). Changes appear in the plain page preview beside the tools; use the header **Preview** action on smaller screens. The admin's neutral light/dark theme is separate and lives in its footer.

## At a glance
- **Presets:** 11 themes, each with light and dark variants.
- **Custom:** Override any color, in both light and dark.
- **Banners:** Gradients or custom images.
- **Social icon shape:** Circle or rounded square.
- **Consent banner:** On by default; asks visitors before embedded media. Profile analytics collection is retired.
- **CSS:** Full custom code support.

Save the page's form with the save bar. The preview can show unsaved values; an assets-only public page changes only after a successful publication. Its light/dark preview toggle does not save a visitor color mode.

## Page layout

Under **Theme → Page layout**, choose **Side by side** for a sticky profile on the left and one vertical block list on the right, or **Stacked** for the profile above the blocks. Mobile always stacks the profile and each block in one column. Saved header grid/carousel settings no longer create cramped multi-column sections.

## Custom Colors

Override individual colors on top of any preset.
- **Primary:** Buttons & Links.
- **Secondary:** Supporting elements.
- **Accent:** Highlights.
- **Background:** Page background.

> **Note:** Overrides apply in **both light and dark mode**. Leave a field empty to use the preset's own color in each mode. Colors saved with an older version stay pinned until you clear them.

## Color Mode

Control what visitors see first.

- **Light:** Always light.
- **Dark:** Always dark.
- **System:** Matches their device (iOS/Android/Windows). Chromium browsers get the right mode on first paint; others switch instantly after load.

## Banners & Profile

Customize the top of your page.

- **Avatar:** Upload and crop.
- **Display Name:** 50 chars max.
- **Bio:** 300 chars max.
- **Verified Badge:** Toggle a blue checkmark (cosmetic).

### Banner Types
1. **Preset Gradients and shaders:** Adapt to your theme colors automatically. Animated shader banners freeze for visitors who prefer reduced motion and have a pause button.
2. **Custom Image:** Upload a supported image up to 5 MiB and use the crop controls.

## Branding / Whitelabel

Control the footer on your public page. **Fully Allowed (MIT).**

- **Show footer:** On/Off.
- **Custom Text:** Replace "Powered by LinkDen".
- **Custom Link:** Change where it links.

Branding also includes the normal site logo/name, favicon, and privacy/terms documents. Sign-in uses the normal site branding; there are no separate login logo or background controls. **Settings → Account → Admin panel branding** separately controls branding in the editor footer.

## Consent Banner

The consent banner is **on by default** and controls third-party embedded media. Profile pages and buttons are not tracked, regardless of this setting.

- **Banner on (default):** Embedded media shows a click-to-load placeholder until visitors click **Load** or allow **Embedded media**.
- **Banner off:** Embeds load immediately. Their providers may process visitor data; review the public privacy notice before changing this setting.

Visitors can change their mind any time with the **Cookie settings** link in the footer. A choice expires after 12 months, or sooner when LinkDen changes what it asks. Escape hides the banner for the current page view without recording a choice.

To configure it:

1. Go to `/admin/design/branding` → **Consent Banner**.
2. Leave **Show consent banner** on unless you deliberately want embeds to load immediately.
3. Edit the banner text and the privacy-policy link (it falls back to your branding privacy URL).

## Custom CSS

For advanced users. Add your own styles.

### Useful Classes
- `.ld-page` - Main container.
- `.ld-profile` - Profile section.
- `.ld-link-block` - Link buttons.
- `.ld-social-block` - Social icons under your profile.
- `.ld-contact-block` - Contact (Connect) form.
- `.ld-header-block`, `.ld-embed-block`, `.ld-image-block`, `.ld-text-block`, `.ld-divider-block`, `.ld-location-block`, `.ld-vcard-block` - The other block types.

> The admin preview scopes CSS to the public page canvas and removes external fetches. The legacy public renderer applies the sanitized CSS. The static publisher rejects unresolved external media/CSS dependencies; it does not silently fetch arbitrary assets.

### CSS Variables
`--ld-primary`, `--ld-accent`, `--ld-background`, `--ld-foreground`, `--ld-card`, `--ld-card-foreground`, `--ld-border`, `--ld-muted`, `--ld-muted-foreground`

```css
/* Example: Gradient Background */
.ld-page {
  background: linear-gradient(135deg, var(--ld-primary), var(--ld-accent));
}
```
