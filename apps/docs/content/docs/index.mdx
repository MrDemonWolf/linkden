LinkDen is an open-source, self-hosted profile page builder. Build your page, keep control of its data, and customize the public design separately from the admin interface.

## What you can do

- **Build a profile page:** nine block types, social icons, an avatar, a bio, banners, and search previews.
- **Choose your layout:** a sticky profile beside a vertical block list on desktop, or a stacked page. Mobile always uses one column.
- **Customize your brand:** 11 public theme presets with light and dark palettes, color overrides, custom CSS, and optional LinkDen branding.
- **Handle messages:** a built-in Inbox, optional Resend delivery, CAPTCHA, and embedded-media consent.
- **Share contact details:** public vCard downloads and a private, signed Apple Wallet pass.
- **Protect the editor:** one administrator, password sign-in, optional TOTP with backup codes, and local-only development login.
- **Back up your data:** JSON export/import.

## Know what is saved and what is public

The editor preview shows your current work in a plain page viewport. It is a visual preview; use **View live** to test real public interactions.

Saving changes updates authoring data. An assets-only public deployment updates after a successful explicit publication. The header's publishing status reports whether publication is configured and verified; saving alone does not prove a deployment.

**Profile analytics collection is retired.** Public pages and buttons send no tracking events.
